# Controller and persistence

D-pad and left stick move focus. A opens the focused entry and B returns to its source screen. L and R page the game shelf or Bank, or select a box. The right stick click toggles motion. The selected entry is indicated by corner brackets, with a dedicated inspector for Boxes, Party, and Bank. The action strip names the controls for the current screen.

Save edits stay in memory until exported with +. Export places a validated copy in a fresh folder and shows its relative path. B asks before leaving a save with unexported edits. Closing a save after export returns to the save list. A Bank deposit is an immediate independent copy. Selecting a Bank entry retains it for pasting into an empty compatible box slot. The Bank entry remains available after paste.

Files with invalid supported-format checksums open read-only when the parser can still identify them. Opening a file, depositing to the Bank, and exporting give text feedback on failure and keep the original SD copy intact.

The editor buffers changes until A applies them. B leaves the editor without
applying its draft. Cross-generation copies and Living Dex box moves show the
destination before applying. Their changes require the same explicit export as
other save edits. Item Bank deposits, park care, and saved walks persist separately
from the active save.

Hold ZL and press ZR, or hold ZR and press ZL, to search when the search
badge is visible. A single trigger runs its listed action on release. Canceling
the keyboard preserves the current selection and filter. Submitting a blank
query clears the filter. Bag item additions search across eligible pouches.
Mystery Gift keeps the query when the archive changes in Filters. L and R jump between sections in the album or select a language copy in card details. X also searches, Y opens filters, and + sorts in the album. A opens a card and X in details stages that exact copy. The staged filter tracks changes for the open session. Export from Boxes.

Opening a Pokémon starts its portrait loop when one is available. Clicking the
right stick switches motion off for the session and shows a fixed pose.
Alcremie's Sweet decoration row previews the chosen sweet in the editor and
uses the same A-to-apply and +-to-export flow as other edits.

Advanced save tools use the same list, inspector and search chord. Long engine
operations run on a worker while the controller view displays the pending task.
Read-only reports stay navigable. A generated edit carries its exact candidate
bytes to review. X accepts that copy, B discards it, and + exports accepted edits.
